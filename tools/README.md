# Ferramentas externas

Cindy Web não baixa, fixa versão nem redistribui Codex, Claude Code ou Hermes. Essa diferença em relação ao Cindy Desktop reduz superfície de supply chain e respeita autenticação/atualização mantida por cada CLI.

Use `npm run doctor` para diagnosticar Node, comandos e workdir. Se no futuro um binário for gerenciado pelo projeto, a mudança deve incluir versão explícita, origem oficial, SHA-256 por plataforma, verificação antes de executar, licença e processo automatizado de atualização revisado pela CI.
